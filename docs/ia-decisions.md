# 정보구조(IA)·페인 역할 확정 (2026-07-02)

> 클라이언트 원안(`_DEV/참고이미지/체육교육회 홈페이지 계획안 0630.pdf`, 29p)을 나인브릿지 셸 패턴에 맞춰 재구성한 확정안. 셸/페인 근거는 [docs/shell-decisions.md] 참조.

## 네비게이션 (4) + 홈(로고) + 마이(아이콘)
```
홈(로고 진입, 네비 밖)  │  프로그램 · 연수안내 · 신청 · 커뮤니티  │  마이(헤더 아이콘)
```
- **소개 전용 메뉴 없음** — 기관소개·인삿말은 홈 콘텐츠로 두고, 필요 시 다른 페이지에서 반복(나인브릿지가 HOME·CONNECT에 소개를 반복하는 방식과 동일).
- 홈 회귀 = 로고(→`/`). 마이 진입 = 헤더 우측 아이콘(→`/my`, OTP 게이트).

## 페이지별 좌/우 페인 역할
| 페이지 | 라우트 | 데스크탑 좌(500) | 데스크탑 우(780) → 모바일=바텀시트 모달 | 셸 패턴 |
|---|---|---|---|---|
| 홈 | `/` | 위젯: 최신 뉴스·다가오는 차수·**최신 갤러리**·기관소개 블록 | 브랜드 로고+슬로건+**신청 CTA**+SNS | 1 |
| 프로그램 | `/program` | 종목 요약카드(스키·스노보드, 준비중 종목) | 과정 상세 **+ 지난 회차 갤러리** | 1/2 |
| 연수안내 | `/courses` | 요약(개요·일정) | 세부: 일정달력·비용표·참고사항 **(탭)** | 1 |
| 신청 | `/apply` | 유형 요약(직무/자율) | 신청폼 + 참고자료 | 3 |
| 커뮤니티 | `/community` | 게시판 리스트(탭) | 글 상세 / 문의폼 | 2 |
| 마이 | `/my` | OTP→내 신청 리스트 | 신청 상세(확인·수정·환불) + 개인 증명문의 | 2 |

## 모바일 규칙
- 좌측(500) 페인만 노출, **데스크탑 우측 세부는 vaul 바텀시트 모달로 대체** (`components/shell/DetailContainer` 재사용).

## 커뮤니티 게시판 5종
공지사항 · **뉴스(언론보도)** · FAQ · 일반문의 · **갤러리**
- 일반문의 = 게시판 형태. 증명문의 = (일반 안내)FAQ + (개인 신청·조회)마이페이지.

## 갤러리 방침 (중요·성장 자산)
회차가 누적될수록 갤러리 비중↑ — "지난 회차를 보는 것이 어떤 텍스트 설명보다 빠른 이해". 저장은 커뮤니티 갤러리, **소비는 여러 곳**:
- 홈 위젯(최신 갤러리 썸네일) · 프로그램 페이지(지난 회차 시각 증거) · (장기) 홈 히어로 이미지 로테이션.

## 콘텐츠·레퍼런스 수급
- 프로그램 상세: 클라이언트에서 정보 수급 → 우리가 가이드 초안 제공 후 채우거나 수정 요청.
- **어드민 + 신청폼 = `_DEV/snowpass` 레퍼런스** (같은 클라이언트의 작년 1차 프로젝트, 검증된 소스). 신청폼 참고자료는 추후 `_DEV`에 추가 공유 예정.

## 로드맵 순서 (기능·데이터 의존 큰 것부터)
1. 구성/스켈레톤(네비·라우트) 정리 ← 지금
2. 프로그램 영역 페이지
3. 연수안내
4. 신청폼
5. 어드민(snowpass 참조)
6. 마이페이지
7. 커뮤니티 게시판 5종 + 홈(인트로) + 기타 독립 페이지 (마지막)
