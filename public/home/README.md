# public/home — 홈 연수코스 카드 이미지

HomeCourses(홈 좌측 연수종류 2열 카드)의 배경 이미지 위치.

## 파일명 (고정 — 코드가 이 경로를 참조)
- `course-jikmu.jpg` — 직무연수 카드 = 실사 06(성인 카빙) + **네이비 듀오톤**
- `course-jayul.jpg` — 자율패키지 카드 = 실사 01(성인+아이) + **그린 듀오톤**

파일이 없으면 코드가 자동으로 브랜드 그라디언트로 폴백하므로 화면은 안 깨짐.

## 규격
- **비율 3:5 세로**, 권장 **750 × 1250 px** (카드 데스크탑 250×417 @3x).
- `object-cover object-center` → 정확히 3:5로 내보내면 크롭 없이 1:1 매핑.
- 구조: **상단 모서리 = + 아이콘(코드), 하단 = 텍스트 밴드(코드).**
  - 인물/주제는 상·중앙에 두고, **하단 눈밭 구간을 텍스트 자리로** 비워둘 것(코드가 하단 검정 그라디언트 스크림을 깐다).
  - + 아이콘: 직무=우상단 / 자율=좌상단. 해당 모서리에 핵심 디테일 배치 지양.

## 듀오톤 (Gradient Map)
- 직무(네이비): 섀도우 `#14263f` → 하이라이트 `#cfe0ec`
- 자율(그린): 섀도우 `#1c3f31` → 하이라이트 `#cfe8d8`
- 두 카드에 동일 매핑 로직 적용(색만 다르게) → 한 세트로 보이게.

## 백업 경로(자연 풀컬러 실사)
듀오톤 대신 자연 풀컬러를 쓸 경우 `HomeCourses.tsx`의 각 코스 `tint` 값을 `0.10~0.18`로 올리면 브랜드 컬러 오버레이로 두 컷 톤을 통일.
