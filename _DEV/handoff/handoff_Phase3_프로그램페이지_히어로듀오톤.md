## 이번 세션 완료

### 1. 프로그램 페이지(`/program`) 전면 재작성
셸 = `/courses` 정본 미러링. 좌 = 단일 마스터 / 우 = 상세. **모바일은 이번에 손 안 댐(다음에 정리)**.
- **좌 마스터(`ProgramMaster`)** — 종목 카드: 제목 + 요약 desc. 폰트 = 연수안내 유형카드 desc 계열(`card-sub`)에서 한 단계 업(13px)·줄간격 relaxed(`DESC_CLS`). 배경 하이라이트만(장식 없음), 준비중 캡션.
- **우 페인 상세** — 히어로 → 과정소개(단락) → **연수 핵심 목표(인포그래픽: 넘버+제목+설명 3블록)** → **세부 커리큘럼(스키/스노보드 그룹, 반명·대상·교육목표)**. 콘텐츠는 전부 클라이언트 확정 카피(`PROGRAM_DETAIL`·`CURRICULUM` 맵).
- **우측 상단 탭 제거** — 히어로 도입 + 좌 마스터가 종목 선택 담당. courses·application 탭은 유지.
- ⚠ 좌 카드 요약 desc와 우 과정소개가 둘 다 소개 성격 → 겹침 여부 오너 확인 필요(현재 둘 다 유지).

### 2. 실사 듀오톤 히어로 (핵심 산출물)
`public/program/hero.jpg` (2100×600, 3.5:1). 소스 2장 = `_DEV/참고이미지/그라데이션/`(스키·스노보드).
- **홈 듀오톤 개념 확장**: 스노보드=블루 톤 / 스키=그린 톤, **은근한 사선 그라데이션**으로 블렌드. 컬러 오버레이 아님 — 톤을 각 사진에 그라디언트맵으로 구워넣음.
- **베이크 스크립트 = `_DEV/bake_hero.py`** (파라미터화, 재현 가능). 튜닝 지점:
  - 톤: `NAVY`/`GREEN`(그라디언트맵 shadow→high) · 채도 `COLOR_MIX`(0.22)
  - 사선 전환: 스키 페더 `f0,f1,tilt`(0.0/0.64/0.18 — f1↑=넓고 은근)
  - 스노보더 = 라이더 줌인 크롭 레이어(`SNB_BOX`·`SNB_H`·`SNB_X`·`SNB_DROP`), 블러 필드 위 배치
  - 스키 = 우측 불투명 구간 배치(선명), `_ski.crop(...*0.92)`로 크기 조절
  - `GRAD_OP=0` (컬러 워시 오버레이 OFF — 이미지 톤만으로 그라데이션)
- 컴포넌트(`ProgramHero`)는 이미지 없으면 네이비 그라디언트 폴백(홈 방식). 단일 합성이라 `heroImgs:['/program/hero.jpg']`, `heroTint:0`.

### 3. 연수안내(`/courses`) 잔손질
- 우측 상단 `ProgramTabs` 추가(신청 페이지와 동일, 좌 마스터와 상태 공유).
- 좌 마스터 유형카드 rounded-0(`CourseTypeMetaCard` `square` prop — 모바일 카드는 rounded 유지).
- 추가렌탈 4항목 데스크탑 `flex-wrap`+`whitespace-nowrap`(스키복상하의 2줄 방지).
- 자율 리프트권 문구: `옵션별 상이(아래 표)` → `옵션별 상이 *하단 표 참조`.

## 다음 세션 (확정 컨셉 — 나머지 페이지 히어로)

**히어로 확장 규칙 (오너와 확정):**
- **톤 = 종목(프로그램) 축** — 스키·스노보드 = 블루/그린 **고정**. 종목의 프로그램·연수안내·신청 히어로 전부 같은 톤. 새 종목(테니스 등) 열릴 때 그 종목 전용 톤 페어.
- **사진 = 페이지 축** — 페이지별 다른 사진(장면 유형 다르게: 프로그램=액션 / 연수안내=슬로프·리조트 / 신청=강습·그룹 등).
- ❌ 페이지마다 색만 바꾸기(템플릿 재탕 + 기존 네이비=직무/그린=자율 의미 충돌). ❌ 둘 다 바꾸기(응집력 상실).

**작업 순서:**
1. 연수안내·신청 히어로용 스키·스노보드 사진 셀렉(가로형, 피사체 좌/우 분리 배치 가능한 컷).
2. `bake_hero.py`를 종목별 톤 프리셋 구조로 소폭 확장(스키=블루/그린 프리셋화) + 페이지별 소스만 교체해 베이크.
3. `/courses`·`/application` 우측 페인 상단에 히어로 삽입(프로그램과 동일 패턴). courses는 현재 상단 탭 있음 → 히어로 도입 시 탭 처리 재검토.
4. 모바일 히어로/탭 정리(이번에 미룸).

## 유지·주의
- 히어로 재베이크는 `_DEV/bake_hero.py` 한 곳. 소스 이미지는 `_DEV/참고이미지/그라데이션/`(미트래킹, 베이크 결과만 커밋).
- 프로그램 커리큘럼·과정소개는 클라이언트 확정 카피 → 임의 창작 금지, `CURRICULUM`/`PROGRAM_DETAIL` 맵만 교체.
