# 라이브 확인 체크리스트 — 동반인 후속입력 1~5단계

작성 2026-07-06. 브랜치 main. 대상 = 동반인 후속입력(자율패키지) 전체 플로우 라이브 검증.
관련 메모리 `[[companion-detail-post-signup-fill]]` · `[[jayul-apply-form-spec]]` · `[[design-taste-crisp-minimal]]`.

---

## 0. 사전 준비
- [ ] `npm run dev` 실행
- [ ] **env 확인** — `MY_SESSION_SECRET`(마이·셀프필 토큰 서명), `APP_ENC_KEY`(뒷자리 암호화) *← 없으면 토큰발급·저장에서 에러*
- [ ] Supabase seed `11`(발번) 적용됨 / `09`·`10`(증명서·더미) — 미실행이면 **자율 신청 1건 직접 제출**로 대체

## A. 자율 신청폼 (1·2단계)
- [ ] 기초강습 3옵션(스키/보드 기초반·프리라이딩) 노출·선택
- [ ] 대여장비(스키/보드 세트) 노출·선택
- [ ] **동반인 명단 입력 섹션 없음** — 대표 + 인원수 + 옵션만
- [ ] 인원 N명 제출 → 성공, 발번 `{종목}FP-YY-00001`(자율=FP)

## B. 어드민 신청관리 (3단계)
- [ ] `/admin/applications`에서 자율건 열기 → 대표 + **빈 슬롯 N-1개**("동반 2"…)
- [ ] 대표 행에 기초강습·대여장비 표기
- [ ] 참가자 "입력/수정" → 모달 **확장필드**(성함·연락처·기초강습·장비·의류사이즈 + 생년월일·성별·뒷자리) 노출 → 저장 → 참가자표 반영
- [ ] **직무건** 모달은 3필드(생년월일·성별·뒷자리)만 — 대조
- [ ] 뒷자리 입력 후 "보험 뒷자리 표시" 복호 정상

## C. 마이페이지 대표 대신입력 (4단계)
- [ ] `/my` → 이름+전화+생년월일 본인확인 → 자율 카드 선택
- [ ] 상세 하단 **"참가자 정보"** 영역, 슬롯별 미입력/입력완료 배지
- [ ] 슬롯 펼침 → 전 필드 입력 → 저장 → 배지 입력완료 전환 + 요약 표시
- [ ] 저장값이 **어드민 신청상세에 반영**됨(교차확인)
- [ ] 모바일(바텀시트) + 데스크탑(우측 페인) 둘 다

## D. 셀프필 링크 (4·5단계)
- [ ] 마이 "참가자 정보" 영역의 **"동반인 입력 링크 복사"** 클릭 → "✓ 복사되었습니다"
- [ ] 복사 URL을 **새 시크릿창/다른 기기**에 붙여넣기(= 마이 세션 없이) → `/fill` 페이지 로드
- [ ] 셀프필 페이지: 헤더에 대표명·연수유형·일정, 참가자 슬롯 목록
- [ ] 동반인 슬롯 펼침 → 본인 정보 입력 → 저장 → 입력완료 배지
- [ ] 셀프필 저장값이 **어드민·마이에 반영**됨
- [ ] **어드민 상세**의 "셀프필 링크 복사"(자율만) → 같은 방식 동작
- [ ] **잘못된/만료 토큰**(URL 끝 한 글자 변경)으로 접속 → "유효하지 않거나 만료된 링크" 에러

## E. 보안·공통
- [ ] 셀프필/마이 로스터에 **주민번호 뒷자리 절대 노출 안 됨**(입력만 가능, write-only)
- [ ] 날짜 슬래시 / 입력 16px / 선택·포커스 틴트만(하드 테두리·ring 없음)
