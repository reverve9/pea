## A. 자율 신청폼 (1·2단계) — *새 1건을 직접 제출해 폼 자체 검증(더미 아님)*
- [ ] 기초강습 3옵션(스키/보드 기초반·프리라이딩) 노출·선택
- [ ] 대여장비(스키/보드 세트) 노출·선택
- [ ] **동반인 명단 입력 섹션 없음** — 대표 + 인원수 + 옵션만
- [ ] 인원 N명 제출 → 성공, 발번 **SFP-27-00006~**(더미가 1~5 점유 → 실제 발번은 6번부터)
  → 제출 직후 어드민에서 대표 + 빈 슬롯 N-1개 생성되는지 확인(B로 이어짐)

## B. 어드민 신청관리 (3단계) — `/admin/applications`
- [ ] **[SFP-27-00002 열기]** 자율건 = 대표(윤서아) + **빈 슬롯 2개**("동반 2"·"동반 3")
- [ ] 대표 행에 기초강습(스키 기초반)·대여장비(스키) 표기
- [ ] **[SFP-27-00002 → "동반 2" 슬롯]** "입력/수정" → 모달 **확장필드**(성함·연락처·기초강습·장비·의류사이즈 + 생년월일·성별·뒷자리) → 저장 → 참가자표 반영
  → 대조: **[SFP-27-00003]** 동반1(임하람)은 이미 **입력완료** 상태로 표시됨
- [ ] **[SCT-27-00003 박도윤 열기]** **직무건 모달 = 3필드(생년월일·성별·뒷자리)만** — 자율 확장필드와 대조 *(박도윤은 뒷자리 미입력이라 admin이 채우는 흐름 그대로 재현됨)*
- [ ] 뒷자리 입력 후 "보험 뒷자리 표시" **복호 정상**
  → 직무 복호 = **[SCT-27-00001 김민준]**, 자율 복호 = **[SFP-27-00004]**(3건) 또는 SFP-27-00003(임하람 1건)

## C. 마이페이지 대표 대신입력 (4단계) — `/my`
- [ ] **[SFP-27-00003 임준서]** 본인확인(**임준서 / 01022220003 / 910820**) → 자율 카드 선택
- [ ] 상세 하단 **"참가자 정보"** 영역, 슬롯별 미입력/입력완료 배지
  → SFP-27-00003 = **대표 완료 + 동반1 입력완료 + 동반2 미입력** → 배지 혼재로 한눈에 대조 가능
- [ ] **[SFP-27-00002 → "동반 2"]** 슬롯 펼침 → 전 필드 입력 → 저장 → 배지 **입력완료 전환** + 요약 표시
  (로그인: **윤서아 / 01022220002 / 930712**)
- [ ] 저장값이 **어드민 신청상세(SFP-27-00002)에 반영**됨(교차확인)
- [ ] 모바일(바텀시트) + 데스크탑(우측 페인) 둘 다
- [ ] **[SFP-27-00001 강태호]** 1인 건 = "참가자 정보"에 후속입력 대상 없음(대표만) — 엣지
- [ ] **[SFP-27-00005 오예린]** completed 상태인데 동반 3명 미입력 → 완료건도 후속입력 되는지 — 엣지

## D. 셀프필 링크 (4·5단계)
- [ ] **[SFP-27-00002 또는 00005]** 마이 "참가자 정보"의 **"동반인 입력 링크 복사"** → "✓ 복사되었습니다"
- [ ] 복사 URL을 **새 시크릿창/다른 기기**에 붙여넣기(= 마이 세션 없이) → `/fill` 페이지 로드
- [ ] 셀프필 헤더에 대표명·연수유형·일정(SFP-27-00002 = **윤서아 / 자율 / 주중2박 2차수**), 참가자 슬롯 목록
- [ ] 동반인 슬롯 펼침 → 본인 정보 입력 → 저장 → 입력완료 배지
- [ ] 셀프필 저장값이 **어드민·마이에 반영**됨
- [ ] **[SFP-27-00003 어드민 상세]** "셀프필 링크 복사"(**자율만**) → 같은 방식 동작
  → 대조: **[SCT-* 직무 상세]**엔 셀프필 링크 없음
- [ ] **잘못된/만료 토큰**(URL 끝 한 글자 변경)으로 접속 → "유효하지 않거나 만료된 링크" 에러
