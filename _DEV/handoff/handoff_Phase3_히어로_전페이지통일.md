# Handoff — 실사 듀오톤 히어로 전 페이지 통일 (2026-07-07)

## 개요
소개형/브랜드 페이지 우측 페인 상단(+모바일)에 **실사 듀오톤 히어로**를 넣는 시스템을 4개 페이지에 통일 적용.
톤 = 종목 축(스키·스노보드 = 네이비+그린 사선 듀오톤 고정) / 사진 = 페이지 축(페이지별 다른 장면).

## 공용 컴포넌트
`components/features/DuotoneHero.tsx` — props: `eyebrow` `title` `imgs`(1~2장) `tint`.
- 2장이면 사선 마스크 블렌드(프로그램), 1장이면 단일 컷.
- 이미지 없으면 네이비 그라디언트 폴백. 스크림·텍스트는 컴포넌트 CSS가 처리(베이크엔 스크림 없음).
- 폰트: 영문 Raleway `clamp(11,2.6cqi,12px)` w400 uppercase 자간3px 시안#a9e0ea / 국문 S-CoreDream `clamp(16,3.6cqi,18px)` w300 자간1px 화이트, mt-1, 좌하단 정렬.
