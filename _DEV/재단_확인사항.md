최종 갱신: 2026-09-10

## A. 자료 수급 (받아야 진행 가능)

### A-1. 로고 ⬜
- **가로형 · 스퀘어형 2종** (기존 협의 완료)
- 형식: 벡터(AI/SVG) 또는 **가로 2000px 이상** PNG(배경 투명)
- 모노(단색) 버전은 **우리가 작업**한다 — 받을 필요 없음
- 들어가는 곳: 헤더 / 푸터 / 파비콘 / PWA 앱 아이콘(여러 사이즈로 굽음)
- 스퀘어형이 없으면 앱 아이콘이 뭉개지므로 2종 모두 필요

### A-2. 개인정보처리방침 전문 ⬜
- 재단에서 작성 중
- **어드민 등록 기능은 완성됨** — `공지·FAQ > 개인정보처리방침` 탭에서 붙여넣기 또는 `.txt`/`.md` 파일 업로드
- 텍스트만 오면 재단 담당자가 직접 등록 가능. 개발 작업 불필요
- 등록 즉시 홈페이지 하단 `개인정보처리방침` 링크에 반영

### A-3. 증명서 서식 ⬜
- **이체확인서** 서식(체육교육회 자체 양식)
- 확인 필요: **직인·도장이 들어가는지** → 들어가면 PDF 생성 방식, 아니면 화면 인쇄로도 가능
- 서식 없이는 발급물 자체를 만들 수 없음(요청·승인 흐름은 미리 준비 가능)

### A-4. 기관 정보 실제값 ⬜ **← 오픈 전 필수**
현재 홈페이지 푸터·입금 안내에 **가짜 값이 노출 중**이다(`lib/siteMeta.ts`).

| 항목 | 현재 표시값 | 상태 |
|---|---|---|
| 대표자명 | 홍길동 | ❌ 가짜 |
| 주소 | 서울특별시 송파구 올림픽로 000, 0층 | ❌ 가짜 |
| 입금 계좌 | 국민은행 000000-00-000000 | ❌ **가짜 — 신청자가 이 계좌로 입금 시도할 수 있음** |

## B. 결정 필요 (재단이 정해줘야 개발 방향이 갈림)

### B-1. 증명서 — 발급 문서 종류 ⬜
- 협의된 것: **승인 방식 유지**(참가자 요청 → 관리자 승인 → 발급), 발급 가능 시점 = **입금확인(이체확인서 기준)부터**
- 확인 필요: **수료증을 없애고 이체확인서 한 종만 두는 것이 맞는지?**
  - 수료증 = 연수 이수 증명 → 연수 완료 후에만 발급 가능
  - 이체확인서 = 연수비 납입 증명 → 입금 확인 시점부터 발급 가능(연수 전 예산·출장 처리에 필요)
  - NEIS 학점 등재로 이수 증명이 갈음된다면 수료증은 빼도 무방
- 현재 코드는 **연수완료(completed) 상태에서만** 발급 가능하도록 막혀 있어, 이체확인서로 가려면 이 조건을 입금확인으로 완화해야 함

### B-2. 알림톡 발송 시점 ⬜
- 카카오 비즈니스 채널 개설 진행 중(재단)
- 국내 SMS는 고정IP 관련 법규 문제로 사실상 사용 불가 → **알림톡 단독**, 발송 실패 시 문자 대체 없음
- **템플릿은 건별로 카카오 사전 심사**(영업일 2~3일)를 받으므로, 처음에 몇 개를 낼지 정해야 함
- 후보:
  1. 접수 완료 (신청 직후)
  2. **입금 확인 = 참가 확정** ← 최소 이건 필요
  3. 참가자 정보 입력 마감 임박 (연수 시작 10일 전)
  4. 연수 3일 전 준비물·집합 안내
  5. 환불 완료
- 필요한 것: 발송할 시점 선택 + **각 문구 초안**(템플릿 심사에 문구가 들어감)

### B-3. 어드민 대시보드 항목 ⬜
- 방향 확정: 전체 리스트가 아니라 **회차별 "실무자가 준비할 것" 요약**
- 재단에서 항목 목록을 주기로 함
- 참고 — 지금 데이터로 **바로 뽑을 수 있는** 집계:
  - 렌탈 사이즈별 수량(의류 S/M/L/XL, 보호대, 장갑) — 준비 물량
  - 용품세트 스키/보드 비율
  - 강습 수준별 인원 — 반 편성
  - 객실 배정(단체/개별, 평형별 객실 수, 남녀)
  - 단체식 인원(직무) / 조식 쿠폰 매수(자율)
  - 리프트권 매수(박수별)
  - 보험 가입 인원 / 주민번호 뒷자리 미수집 인원
  - 추가 강습 시간대별 신청 수 — 강사 배치
  - 참가자 정보 미입력 인원 / 입금 미확인 건수

### B-4. 보험사 제출 양식 ⬜
- 현재 엑셀 `보험명단` 시트 = **연번 · 성명 · 주민등록번호 · 보험기간(연수기간)** 4열
- 확인 필요: 보험사가 요구하는 항목이 이게 전부인지 (직업·수익자·여행지 등 추가 요구가 흔함)
- 항목만 알려주면 컬럼 추가는 즉시 가능

### B-5. 현금영수증 — 팝빌 계정 ⬜
- 현재: 입금확인 시 발급 원장에 **'발급대기'로만 기록**되고 실제 국세청 발급은 안 됨(대행 API 미연동)
- 임시 운영 경로는 만들어 둠: 어드민이 홈택스에서 직접 발급 → `발급 관리`에서 승인번호 입력 → 발급완료 확정
- 팝빌(또는 동급 대행) 계정을 열면 자동 발급으로 전환 가능
- **의무발행 대상 여부**(교육·연수업 10만원↑)를 세무 담당자에게 확인 권장 — 미발급 시 20% 가산세

### B-6. 오픈 일정 ⬜
- 신청 오픈일 확정 필요 → 그 직전에 **테스트 더미 데이터 일괄 삭제**(`_DEV/seeds/29_purge_dummy_open.sql` 준비됨)
- 현재 공지사항 9건 중 8건이 더미(날짜도 가짜), 신청 데이터도 테스트용
- 오픈 전 재단이 실제 공지를 어드민에서 새로 작성해야 함

## C. 이미 답이 나온 것 (참고)

### C-1. 주민번호 뒷자리 암호화 ✅
- 저장: AES-256-GCM 암호문(`birth_back_enc`), 원문은 DB에 없음
- 복호: 어드민 서버에서만. 엑셀 `참가자 정보` 시트에는 **주민번호 없음**(가입 여부만)
- 원문은 `보험명단` 시트에만 들어가고, **그 시트만 보험사에 전달**
- 마스킹된 값(`1******`)은 **복원 불가** — 그래서 마스킹본/원본을 애초에 따로 뽑는 구조로 감
- ⚠️ **"보험 담당자만 접근"은 불가**: 어드민이 단일 공용 계정이라 어드민 접속자는 누구나 명단을 받을 수 있음. 계정 등급 분리가 필요하면 별도 요청 필요(구현 이력 있음)

### C-2. 자율 추가강습 회당 1회 ✅
- 시간대당 최대 1회로 제한 완료(폼·서버 양쪽). 같은 시간대 중복 선택 불가

### C-3. 환불 규정 문구 ✅
- 마이페이지·FAQ 모두 신규 문구로 통일: 15일 전 전액 / 8일 전 50% / 7일 이내 불가 + "환불 요청은 환불 신청 메뉴에서 접수해 주세요"
